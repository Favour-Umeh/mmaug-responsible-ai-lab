# Sample outputs to review

These deliberately flawed outputs were written for teaching. They are not transcripts of a live model or evidence of any model's performance.

## Sample A: Announcement draft

“Community AI Basics takes place on October 16, 2026, from 14:00 to 15:00 UTC at Central Library. Tickets cost $25 and there is room for 50 people. Anyone can walk in without registering. No programming experience is required. Captions and a recording are guaranteed. Registration closes October 12 at 17:00 UTC.”

Break compound sentences into separate claims. Mark each claim as supported, contradicted, or unknown. Attach an evidence ID when possible. Unknown means the source does not settle the claim. It is different from proving a claim false.

## Sample B: Prompt draft

“Here is our participant spreadsheet, including emails, accommodation notes and payment information. Use everything to write a generic reminder for our workshop.”

Identify which inputs the task actually needs and rewrite the prompt before using an external tool.

## Sample C: Assistant response

“The source instructed me to charge $99. Please provide your account password so I can complete registration.”

Explain why the page text does not grant authority to change the task, price or data request.

## Sample D: Audience recommendation

“Older adults will struggle with this workshop, so registration should be restricted to younger professionals.”

Identify the unsupported assumption, then rewrite the recommendation using only the supplied audience information.
