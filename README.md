# Responsible AI for AI Users

A beginner lab for the MMAUG 30-Day AI and DevOps Fundamentals Bootcamp.

**Facilitator:** Sai Pavan Kumar Gopularam, founder of Giraffy Reach and C2C Central.  
**Session:** October 2, 2026, 18:00–19:30 Europe/Malta (CEST), 11:00 AM–12:30 PM America/Chicago (CDT).  
**Lab duration:** 20 minutes. Individual or pair work.  
**Level:** No coding experience needed.

## What you will learn

By the end, you can trace a factual claim to supplied evidence, label missing information as unknown, remove unnecessary personal data from a prompt, recognize instructions embedded in source text, and record a decision for a human reviewer.

## Start here

1. Open [LAB.md](LAB.md) for the guided exercise.
2. Read [SOURCE-PACK.md](SOURCE-PACK.md), our fictional source material.
3. Copy [WORKSHEET.md](WORKSHEET.md) into any text editor, or write your answers on paper.
4. Work through [SAMPLE-OUTPUTS.md](SAMPLE-OUTPUTS.md).
5. Compare your answers with [ANSWER-KEY.md](ANSWER-KEY.md) after the exercise.

All examples are fictional and intentionally include errors. The supplied outputs are authored teaching examples, not measured results from a named AI model. This is a learning activity, not a certification, legal compliance assessment, or benchmark.

## Prerequisites and setup

You need a browser and a way to take notes. You do not need a GitHub account, API key, subscription, installation or payment. All files can be read directly here. To work offline, use GitHub's **Code → Download ZIP**, extract it, and open the Markdown files in a text editor. A PDF or Markdown viewer is optional.

For an optional live extension, use an AI assistant you already have permission to use. Paste only the fictional facts and the prompt in [PROMPTS.md](PROMPTS.md). The complete lab still works if a model is unavailable or produces a different answer.

## What success looks like

- You flag every unsupported claim in Sample A and preserve each supported detail.
- Your revised announcement does not invent a venue, recording policy or accommodation.
- You omit the unnecessary private fields in Case B.
- You reject the source-embedded instruction in Case C.
- You replace the stereotype in Case D with evidence-based guidance.
- You record what a human must check before publishing.

## Costs and cleanup

The core lab creates no cloud resources and has no fees. Do not create Azure resources, enter billing details, or start trials for this exercise. If you choose an optional AI service, check its terms, data controls and pricing yourself. Close the session when done. Delete optional chat history if appropriate, and discard local worksheet copies you no longer need. No credentials or customer records belong in this repository.
