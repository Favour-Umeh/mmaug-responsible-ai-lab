# Guided lab: Review an AI draft before anyone uses it

**Time:** 20 minutes. **Work mode:** individual or pairs.  
**Inputs:** source pack, sample outputs, worksheet. No live AI tool is required.

## 1. Set the task and authority (2 minutes)

Read Case A in [SOURCE-PACK.md](SOURCE-PACK.md). Your task is to prepare a public event announcement. The approved source pack supplies the facts. You are the reviewer, and an organizer will authorize publication. Do not send or publish any announcement during this exercise.

Open [WORKSHEET.md](WORKSHEET.md) and write this purpose at the top. Note that an AI draft cannot authorize its own publication.

## 2. Check claims against evidence (7 minutes)

Read Sample A in [SAMPLE-OUTPUTS.md](SAMPLE-OUTPUTS.md). Split compound claims: “captions and a recording” contains two claims with different evidence. Fill in your claim log for each distinct claim. Use:

- **Supported:** the source directly supports the claim.
- **Contradicted:** the source states a different fact.
- **Unknown:** the source does not establish the claim.

For each error, write a correction or a question for the organizer. Do not ask the AI whether its own output is correct as your only check. If a source were outdated or disputed in real work, seek a current authoritative source before acting.

## 3. Repair the announcement (3 minutes)

Write a short version containing the correct name, date, UTC time, online format, free attendance, required registration, capacity and registration cutoff. Include the supported beginner/caption details if useful. Treat the recording as unconfirmed. Do not invent a registration link. Check the revised version against the source pack again.

## 4. Check data, instructions and assumptions (5 minutes)

Discuss Cases B, C and D and record answers in the worksheet.

- B: Which fields can you remove? Rewrite the prompt using only the information the generic reminder needs.
- C: Which words are an embedded instruction? What should the reviewer do about the price and password request?
- D: What assumption did the draft invent? Write an inclusive version supported by the source.

Use fictional inputs only. No actual account passwords, participant records or payment data should enter any tool.

## 5. Make a review decision (3 minutes)

Compare with [ANSWER-KEY.md](ANSWER-KEY.md). Write a decision: **revise**, **request clarification**, or **ready for organizer review**. Explain why. Include a named role that has authority to approve publication, and the unresolved registration-link question.

A model-generated statement, polished wording, or citation-shaped text is not sufficient evidence by itself. The human reviewer still needs to inspect the source and the action being proposed.

## Optional extension (5–10 minutes after the core lab)

Use [PROMPTS.md](PROMPTS.md) in an approved AI tool, or have a partner play the assistant. Compare the result against F1–F9. Record the prompt and observed output, but do not infer a model-wide accuracy score from one example. Never publish private chats in this repository.

## Completion check

The answer key explains every Sample A claim and gives worked responses for B–D. If you disagree, point to evidence and explain the classification. You complete the lab when your final announcement contains no unsupported claims and your review record makes the remaining human decision clear.
